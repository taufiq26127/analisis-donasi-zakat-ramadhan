Segmentasi Donatur: Tier Kontribusi
Tim fundraising ingin mengelompokkan donatur ke dalam tier berdasarkan total kontribusi mereka selama Ramadan, supaya bisa menyesuaikan strategi komunikasi untuk masing-masing tier.

Buat segmentasi donatur dengan aturan tier:

Platinum: total donasi >= 5.000.000
Gold: total donasi >= 2.000.000
Silver: total donasi >= 500.000
Bronze: di bawah 500.000
Yang harus ditampilkan:

nama: nama donatur
kota: kota donatur
total_donasi: total kontribusi selama Ramadan
tier: kategori tier sesuai aturan di atas

with ddonatur as (
select
donasi.donatur_id,
sum(jumlah) as total_donasi,
case
when sum(jumlah) >= 5000000 then 'Platinum'
when sum(jumlah) >= 2000000 then 'Gold'  
 when sum(jumlah) >= 500000 then 'Silver'  
 else 'Bronze' end as tier
from donasi
group by donatur_id
)

select
nama,
kota,
tier,
total_donasi
from ddonatur
join donatur on ddonatur.donatur_id = donatur.id
order by total_donasi desc
