Ranking Donatur Paling Dermawan
Koordinator wilayah ingin tahu siapa donatur paling dermawan di setiap kota, supaya bisa memberikan apresiasi dan menjalin hubungan lebih dekat.

Buat ranking donatur berdasarkan total donasi, dikelompokkan per kota.

Yang harus ditampilkan:

nama: nama donatur
kota: kota donatur
total_donasi: total kontribusi
ranking_kota: urutan ranking dalam kota tersebut (1 = tertinggi)

with ddonatur as (
select
donasi.donatur_id,
sum(jumlah) as total_donasi,
case
when sum(jumlah) >= 5000000 then 'Platinum'
when sum(jumlah) >= 2000000 then 'Gold'  
 when sum(jumlah) >= 500000 then 'Silver'  
 else 'Bronze' end as tier
from donasi
group by donatur_id
)

select
nama,
kota,
total_donasi,
dense_rank() over(partition by kota order by total_donasi desc) as ranking_kota
from ddonatur
join donatur on ddonatur.donatur_id = donatur.id
order by kota asc, total_donasi desc
